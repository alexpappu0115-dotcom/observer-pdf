# Observer — Full PDF Studio

Local-first Acrobat alternative with the complete feature set.

## Features
- Open & view multi-page PDFs
- **Draw** freehand annotations (ink layer)
- **OCR** current page (Tesseract.js, on-device)
- **Visual signature** + **Certified digital signature** (PKCS#7, self-signed X.509 recognized by Acrobat)
- Rotate / delete pages
- Combine multiple PDFs
- Save annotated/signed PDF
- Dark Quire-inspired branding (ink / cream / brass / clay)
- Works on iPhone Safari, PWA (Add to Home Screen)
- 100% client-side — nothing uploaded

## Quick Start on iPhone
1. Open the GitHub Pages URL (once enabled) or serve locally.
2. Add to Home Screen for app-like experience.

## Local Server (recommended)
```bash
python3 -m http.server 8000
```
Then open `http://[your-ip]:8000` on the phone (same Wi-Fi).
