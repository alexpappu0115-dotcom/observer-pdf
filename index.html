    Digital ID

    Without an imported certificate, Observer creates a self-signed Digital ID per name and keeps it on this device, so all your signatures share one identity. Acrobat will show it as "identity unknown" until the recipient trusts it. Import a certificate from a trusted provider (.p12 / .pfx) to get signatures Acrobat validates automatically.

    Privacy & data

    Everything happens on this device: rendering, OCR, drawing and signing. Files only leave it when you save them somewhere yourself. The one exception is the optional RFC 3161 timestamp, which sends a hash — never the document — to a public timestamp server. If that server does not allow browser requests, Observer simply signs without it.

    Clearing removes your settings, saved signature drawing and Digital IDs from this browser. Back up your Digital ID first if you still need it.

    About

    Observer PDF StudioVersion — GitHub

    A local-first PDF studio: read, search, annotate, OCR and digitally sign without uploading anything.

    On signature trust: Observer signs with PKCS#7 detached (adbe.pkcs7.detached) and SHA-256. A self-signed Digital ID is cryptographically sound — it proves the file has not changed since signing — but no public authority vouches for who holds it, so Acrobat shows "signature validity is unknown" until the recipient trusts the certificate. It is not on the Adobe Approved Trust List. Import a certificate from a trusted CA for signatures that validate automatically.
